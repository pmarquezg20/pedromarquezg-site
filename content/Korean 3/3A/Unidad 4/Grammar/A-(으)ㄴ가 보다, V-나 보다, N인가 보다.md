# Grammar 1 - A-(으)ㄴ가 보다, V-나 보다, N인가 보다

Unidad: [[Korean 3/3A/Unidad 4/Index - Unidad 4|Unidad 4: 먹어 보니까 맛있던데요]]
Fuente: Student Book 3A (p. 96 + appendix p. 248) + audios de la app koreano.
Seccion: 문법

## La idea clave
`A-(으)ㄴ가 보다, V-나 보다, N인가 보다` = **"Parece que..." (deduciendo de lo que ves)**

Ves una pista y sacas la conclusión. La clave es que la experiencia sea INDIRECTA: mirando el zapato dices 발이 큰가 봐요, pero mirando el pie ya no —ahí lo estás viendo directo y va 큰 것 같아요. Si no hay ninguna pista y solo es tu opinión, tampoco sirve.

## Forma
`A-(으)ㄴ가 보다 (아프다→아픈가 보다) · V-나 보다 (오다→오나 보다) · N인가 보다 | Pasado (A y V): -았나/었나 보다`

|  | 받침 X | 받침 O |
|---|---|---|
| 형용사 | 아프다 → 아픈가 보다 | 많다 → 많은가 보다 |
| 동사 | 오다 → 오나 보다 | 읽다 → 읽나 보다 |
| 명사 | 의사 → 의사인가 보다 | 학생 → 학생인가 보다 |

## Ejemplos del libro (예문)
Dialogo de la caja (track 36):

| Coreano | Español |
|---|---|
| A: 식당 앞에 사람들이 많이 서 있네요. | Hay mucha gente haciendo fila frente al restaurante. |
| B: 저 식당 음식이 맛있나 봐요. | Parece que la comida de ese restaurante es buena. |

| Coreano | Español |

## Appendix del libro (문법 해설)
**Significado (p. 248):** 어떤 사물이나 상황을 보고 동작, 상태를 짐작하여 표현할 때 사용한다. (deducir a partir de lo que se VE)

**Combinación:** 형용사, 동사, 명사

Ejemplos del appendix:

- `수미가 아직도 자고 있네요. 몸이 아픈가 봐요.`
- `비가 오나 봐요. 사람들이 우산을 쓰고 가요.`
- `민수 씨는 참 아는 게 많네요. 책을 많이 읽었나 봐요.`
- `저 사람은 하얀 가운을 입었네요. 의사인가 봐요.`

**주의 / Para deducir sobre el PASADO se usa '-았나/었나 보다', con verbos y adjetivos.**

- `밤에 비가 왔나 봐요. 땅이 젖어 있네요.`
- `수미 씨가 많이 아팠나 봐요. 어제 학교에 결석했어요.`

**주의 / COMPARACIÓN con 'A-(으)ㄴ 것 같다 / V-는 것 같다' (2급 4과): '-(으)ㄴ가 보다' solo sirve cuando la experiencia es INDIRECTA y hay una pista visible; '것 같다' vale para las dos y también para dar una opinión sin pista alguna.**

- `(mirando el zapato) 발이 큰가 봐요. (O) / (mirando el pie) 발이 큰가 봐요. (X)`
- `(las dos) 발이 큰 것 같네요. (O)`
- `내일 축구 경기에서 우리가 이길 것 같아요. — opinión sin pista: solo '것 같다'.`

## Errores típicos de hispanohablantes
- Usarlo viendo la cosa directamente: mirando el pie, ✗ `발이 큰가 봐요` → `발이 큰 것 같아요`.
- Usarlo sin ninguna pista, solo por opinión: ✗ `내일 우리가 이기나 봐요` → `이길 것 같아요`.
- Meter el adjetivo en la forma del verbo: ✗ `아프나 보다` → `아**픈가** 보다`. 형용사 lleva -(으)ㄴ가.

## Machete para Pedro
`A-(으)ㄴ가 보다 (아프다→아픈가 보다) · V-나 보다 (오다→오나 보다) · N인가 보다`

- 저 식당 음식이 맛있나 봐요. → *Parece que la comida de ese restaurante es buena.*
- 식당 앞에 사람들이 많이 서 있네요. → *Hay mucha gente haciendo fila frente al restaurante.*
- 비가 오나 봐요. 사람들이 우산을 쓰고 가요. → *Parece que está lloviendo. La gente va con sombrilla.*
- 밤에 비가 왔나 봐요. 땅이 젖어 있네요. → *Parece que llovió de noche. El piso está mojado.*
