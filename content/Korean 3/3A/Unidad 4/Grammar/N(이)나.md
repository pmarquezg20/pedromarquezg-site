# Grammar 2 - N(이)나

Unidad: [[Korean 3/3A/Unidad 4/Index - Unidad 4|Unidad 4: 먹어 보니까 맛있던데요]]
Fuente: Student Book 3A (p. 97 + appendix p. 249) + audios de la app koreano.
Seccion: 문법

## La idea clave
`N(이)나` = **"Pues... aunque sea" (segunda opción)**

No es lo ideal, pero está bien. Sirve para proponer algo sin insistir: 라면이나 끓여 먹을까요? No lo confundas con los otros dos N(이)나 que ya viste — el de elegir entre varias cosas (2급 1과) y el de cantidad, 'nada menos que' (2급 18과).

## Forma
`받침 X: N나 (영화 → 영화나) · 받침 O: N이나 (책 → 책이나)`

|  | 받침 X | 받침 O |
|---|---|---|
| 명사 | 영화 → 영화나 | 책 → 책이나 |

## Appendix del libro (문법 해설)
**Significado (p. 249):** 최선은 아니지만 괜찮은 정도의 차선임을 나타내거나 가벼운 제안을 할 때 사용한다. (segunda opción / propuesta suave)

**Combinación:** 명사

Ejemplos del appendix:

- `시간 있으면 함께 점심이나 먹어요.`
- `할 일이 없으니까 그냥 잠이나 자야겠어요.`
- `비가 오니까 집에서 파전이나 부쳐 먹고 싶어요.`

**주의 / COMPARACIÓN con los otros dos N(이)나 que ya viste: el de 2급 1과 (elegir entre varias cosas parecidas: 부산이나 제주도에 한번 가 보고 싶어요) y el de 2급 18과 (detrás de una cantidad, 'nada menos que': 커피를 세 잔이나 마셨어요). Este es 'pues… al menos'.**

- `녹차가 없으니까 커피나 마시자. (차선)`
- `부산이나 제주도에 한번 가 보고 싶어요. (2급 1과 · elección)`
- `커피를 세 잔이나 마셨어요. (2급 18과 · cantidad)`

## Errores típicos de hispanohablantes
- Confundirlo con el N(이)나 de elección (2급 1과): `부산이나 제주도` es 'Busan o Jeju', no 'aunque sea Busan'.
- Confundirlo con el de cantidad (2급 18과): `세 잔이나` es 'nada menos que tres tazas'.
- Usarlo con algo que sí es tu primera opción: suena a que te conformas.

## Machete para Pedro
`받침 X: N나 (영화 → 영화나) · 받침 O: N이나 (책 → 책이나)`

- 그럼 라면이나 끓여 먹을까요? → *¿Entonces hacemos aunque sea un ramen?*
- 일요일에 영화나 보러 가요. → *El domingo vamos a ver aunque sea una película.*
- 시간 있으면 차나 한잔 할래요? → *Si tiene tiempo, ¿nos tomamos aunque sea un té?*
- 할 일이 없으니까 그냥 잠이나 자야겠어요. → *Como no tengo nada que hacer, mejor me duermo y ya.*
