## Texto

여러분은 눈처럼 하얀 모래와 수많은 별들이 빛나는 사막에서 잊을 수 없는 하룻밤을 보내시게 될 겁니다. 자세한 일정은 함께 보내 드리는 일정표를 봐 주시고 여기에서는 사막 체험 여행에 대한 간단한 정보와 준비물을 알려 드리려고 합니다.

이곳은 1년 내내 덥고 건조한 편이지만 12월은 기온이 20도 정도로 가장 여행하기 좋은 때입니다. 하지만 일교차가 커서 낮에는 덥지만 밤이 되면 기온이 많이 떨어집니다. 보통 낮에는 최고 기온이 25도, 밤에는 최저 기온이 10도 정도입니다. 사막의 밤이 추울 줄 모르고 여름옷만 가져오시는 분들이 많습니다. 하지만 따뜻한 겨울옷과 양말을 반드시 준비해 오셔야 합니다. 음식과 텐트는 모두 저희가 제공하니까 준비하실 필요가 없습니다.

둘째 날 아침에는 낙타를 타고 사막을 산책하는 프로그램도 준비되어 있으니 원하시는 분은 따로 신청해 주세요. 감사합니다.

사하라 여행사 드림

## Traduccion

Ustedes van a pasar una noche inolvidable en un desierto de arena blanca como la nieve, donde brillan incontables estrellas. Para el itinerario detallado consulten la programación que les enviamos adjunta; aquí les vamos a dar información breve sobre el viaje de experiencia en el desierto y lo que deben llevar.

Este lugar es caluroso y seco todo el año, pero diciembre, con unos 20 grados, es la mejor época para viajar. Sin embargo, la amplitud térmica es grande: de día hace calor, pero al caer la noche la temperatura baja mucho. Normalmente la máxima de día es de 25 grados y la mínima de noche unos 10. Mucha gente viene solo con ropa de verano sin imaginarse que las noches del desierto son frías. Pero es indispensable traer ropa de invierno abrigada y medias. La comida y las carpas las proveemos nosotros, así que no necesitan llevarlas.

La mañana del segundo día también hay un programa para pasear por el desierto en camello, así que quien lo desee debe inscribirse aparte. Muchas gracias.

Atentamente, Agencia de Viajes Sahara

## Desglose completo

> [!tip] Por qué se siente difícil
> No es el vocabulario: es que está escrito en **lenguaje de empresa a cliente**. Cada verbo lleva una o dos capas de cortesía encima (**-시-**, **-아/어 드리다**, **저희**, **분**), así que un verbo simple como «enviar» aparece como **보내 드리는** y «pasar la noche» como **보내시게 될 겁니다**. Si le quitas las capas, las frases son cortas. Abajo se las quito una por una.

### Las tres capas de cortesía que se repiten

| Capa | Qué hace | En el texto |
|---|---|---|
| **-시-** | sube al **sujeto** (el lector) | 보내**시**게, 가져오**시**는, 오**셔**야, 준비하**실**, 원하**시**는, 봐 주**시**고 |
| **-아/어 드리다** | baja al **hablante** (la agencia) al hacer algo *para* el lector | 보내 **드리는**, 알려 **드리려고** |
| **저희 / 분** | «nosotros» humilde y «persona» honorífica | **저희**가 제공하니까, 여름옷만 가져오시는 **분**들 |

Regla práctica: **-시-** es para quien *recibe* la acción de honor (tú, el cliente); **드리다** es la agencia **rebajándose**. Nunca se usa -시- para uno mismo.

### Párrafo 1

#### 1. 여러분은 눈처럼 하얀 모래와 수많은 별들이 빛나는 사막에서 잊을 수 없는 하룻밤을 보내시게 될 겁니다.

| Pieza | Qué es |
|---|---|
| 여러분 | ustedes (a un público) |
| 은 | marca de tema |
| 눈 | nieve |
| **처럼** | **como** (comparación) → 눈처럼 = como la nieve |
| 하얗다 → **하얀** | ser blanco → blanco (modifica al sustantivo; ㅎ irregular) |
| 모래 | arena |
| 와 | y (une sustantivos) |
| 수많다 → **수많은** | ser innumerable (수 número + 많다 mucho) → incontables |
| 별 + 들 + 이 | estrella + plural + sujeto |
| 빛나다 → **빛나는** | brillar (빛 luz + 나다 salir) → que brillan |
| 사막 | desierto |
| 에서 | en (lugar donde pasa la acción) |
| 잊다 | olvidar |
| **잊을 수 없다** → 잊을 수 없는 | no poder olvidar → inolvidable |
| 하룻밤 | una noche entera (하루 un día + 밤 noche, con ㅅ de unión) |
| 을 | objeto |
| 보내다 | pasar (tiempo) |
| **-시-** | honorífico |
| **-게 되다** | llegar a / terminar (pasando algo, sin que uno lo fuerce) |
| **-(으)ㄹ 겁니다** | futuro formal: «va a…» |

**El esqueleto:** 여러분은 … 사막에서 … 하룻밤을 보내시게 될 겁니다
= «Ustedes van a pasar una noche … en un desierto …».

Todo lo demás son **modificadores en cadena**, que en coreano van SIEMPRE delante del sustantivo:

- 눈처럼 하얀 **모래** → arena blanca como la nieve
- 수많은 별들이 빛나는 **사막** → un desierto donde brillan incontables estrellas
- 잊을 수 없는 **하룻밤** → una noche inolvidable

👉 En español ponemos esas descripciones *detrás* («un desierto **donde** brillan…»); en coreano van *delante* y sin «donde». Ese orden invertido es lo que hace que la frase se sienta larguísima.

⭐ **보내시게 될 겁니다** es un bloque de tres capas: 보내다 (pasar) + -시- (usted) + -게 되다 (llegará a) + -ㄹ 겁니다 (futuro). El coreano formal prefiere esto a un simple 보낼 겁니다 porque suena menos como una orden y más como una promesa.

#### 2. 자세한 일정은 함께 보내 드리는 일정표를 봐 주시고 여기에서는 사막 체험 여행에 대한 간단한 정보와 준비물을 알려 드리려고 합니다.

| Pieza | Qué es |
|---|---|
| 자세하다 → **자세한** | ser detallado → detallado |
| 일정 | itinerario, programa |
| 은 | tema (marca el cambio de asunto) |
| 함께 | juntos, adjunto |
| 보내다 | enviar |
| **-아/어 드리다** | hacerlo *para* usted (humilde) → 보내 드리는 = que les enviamos |
| 일정표 | la programación (일정 itinerario + 표 cuadro) |
| 를 | objeto |
| 보다 → **봐 주시고** | ver → háganme el favor de verla, y… (-아/어 주다 + -시- + -고) |
| 여기에서는 | aquí (여기 + 에서 en + 는 contraste: «aquí en cambio…») |
| **N에 대한** | sobre N (modificando a un sustantivo) |
| 간단하다 → **간단한** | ser breve, sencillo |
| 정보 | información |
| 와 | y |
| 준비물 | lo que hay que llevar (준비 preparación + 물 cosa) |
| 알리다 → **알려 드리려고 합니다** | informar → «les vamos a informar» |
| **-(으)려고 하다** | tener la intención de, ir a |

**El esqueleto:** 일정은 일정표를 봐 주시고, 여기에서는 정보와 준비물을 알려 드리려고 합니다
= «El itinerario, véanlo en la programación; aquí les vamos a contar la información y qué llevar».

⭐ Fíjate en el **contraste con 는**: 자세한 일정**은** … 여기에서**는** … El 는 no está marcando el tema principal, está **contrastando dos cosas**: *eso* va en el otro papel, *esto* va aquí.

⭐ **-아/어 주다 vs -아/어 드리다**: los dos significan «hacer algo para alguien». 주다 es neutro; **드리다** es cuando *yo* lo hago para alguien **superior** (el cliente). Por eso la agencia dice 보내 **드리는** (yo te envío) pero le pide 봐 **주시고** (hazme el favor).

### Párrafo 2

#### 3. 이곳은 1년 내내 덥고 건조한 편이지만 12월은 기온이 20도 정도로 가장 여행하기 좋은 때입니다.

| Pieza | Qué es |
|---|---|
| 이곳 | este lugar |
| 1년 **내내** | todo el año, de principio a fin |
| 덥다 → 덥고 | hacer calor → y (une adjetivos) |
| 건조하다 | ser seco |
| **-(으)ㄴ/는 편이다** | «tirar a», «más bien ser» (suaviza la afirmación) |
| -지만 | pero |
| 기온 | temperatura del aire (氣溫) |
| 20도 **정도로** | como a 20 grados (정도 aproximadamente + 로 con ese valor) |
| 가장 | el más |
| 여행하다 → **여행하기 좋은** | viajar → bueno para viajar (**-기 좋다**) |
| 때 | momento, época |

**El esqueleto:** 이곳은 덥고 건조한 편이지만 12월은 가장 여행하기 좋은 때입니다.

⭐ **-(으)ㄴ 편이다** es el «más bien»: 건조한 편이다 no es «es seco» a secas, es «tiende a ser seco». En un anuncio suena honesto sin asustar.

⭐ **-기 좋다** convierte el verbo en sustantivo y le pone una valoración: 여행하기 좋다 (bueno para viajar), 먹기 좋다 (rico de comer), 입기 좋다 (cómodo de llevar).

#### 4. 하지만 일교차가 커서 낮에는 덥지만 밤이 되면 기온이 많이 떨어집니다.

| Pieza | Qué es |
|---|---|
| 하지만 | sin embargo |
| **일교차** | amplitud térmica del día (日 día · 較 comparar · 差 diferencia) |
| 크다 → **커서** | ser grande → porque es grande (**-아/어서** causa; 크다 pierde la ㅡ) |
| 낮에는 | de día (con 는 de contraste) |
| 덥지만 | hace calor, pero |
| 밤이 **되면** | cuando llega la noche (되다 volverse + -(으)면 si/cuando) |
| 떨어지다 | caer, bajar |

**El esqueleto:** 일교차가 커서 … 밤이 되면 기온이 떨어집니다 = «como la diferencia día-noche es grande, al caer la noche baja la temperatura».

⭐ Dos «peros» distintos en una frase: **하지만** conecta con lo anterior (frase nueva) y **-지만** va pegado al verbo dentro de la misma frase.

#### 5. 보통 낮에는 최고 기온이 25도, 밤에는 최저 기온이 10도 정도입니다.

| Pieza | Qué es |
|---|---|
| 보통 | normalmente |
| **최고** | máximo (最高: 最 el más · 高 alto) |
| **최저** | mínimo (最低: 最 el más · 低 bajo) |
| 정도 | aproximadamente, más o menos |

Frase de datos, sin gramática nueva. Los pares **최고/최저** se repiten en pronósticos: 최고 기온, 최저 기온.

#### 6. 사막의 밤이 추울 줄 모르고 여름옷만 가져오시는 분들이 많습니다. ⭐

**Esta es la frase de la unidad**: aquí aparece la gramática 3 (**-(으)ㄹ 줄 몰랐다**).

| Pieza | Qué es |
|---|---|
| 사막**의** 밤 | la noche **del** desierto (의 = de) |
| 춥다 → **추울** | tener frío → (ㅂ irregular: 춥 + 을 = 추울) |
| **-(으)ㄹ 줄 모르다** | no saber / no imaginarse que… |
| -고 | y (une las dos acciones) |
| 여름옷 | ropa de verano (여름 verano + 옷 ropa) |
| **만** | solo, nada más que |
| 가져오다 → **가져오시는** | traer (가지다 tener + 오다 venir) → que traen (usted) |
| 분 + 들 + 이 | persona (honorífico) + plural + sujeto |
| 많습니다 | hay muchos |

**El esqueleto:** 밤이 추울 줄 모르고 여름옷만 가져오시는 분들이 많습니다
= «Hay mucha gente que, sin imaginarse que la noche es fría, trae solo ropa de verano».

⭐ **-(으)ㄹ 줄 몰랐다 / 모르고**: es «no tenía idea de que…». Compara con el título de la unidad:
- 비가 이렇게 많이 올 **줄 몰랐어요** = No me imaginaba que iba a llover tanto.
- 사막의 밤이 추울 **줄 모르고** = sin imaginarse que la noche del desierto es fría.
- Lo contrario existe: **-(으)ㄹ 줄 알았다** = sí lo creía / pensaba que.

⚠️ Ojo con el otro 줄 알다, el de habilidades: 수영할 줄 알아요 = sé nadar. Mismo molde, sentido distinto: con **알다/모르다** + **줄** puede ser «saber hacer algo» o «imaginarse que algo pasa», y lo decide el contexto.

#### 7. 하지만 따뜻한 겨울옷과 양말을 반드시 준비해 오셔야 합니다.

| Pieza | Qué es |
|---|---|
| 따뜻하다 → 따뜻한 | ser abrigado, tibio |
| 겨울옷 | ropa de invierno |
| 과 | y (después de consonante) |
| 양말 | medias, calcetines (洋襪) |
| **반드시** | sin falta, obligatoriamente |
| 준비하다 | preparar, alistar |
| **-아/어 오다** | traerlo ya hecho desde antes → 준비해 오다 = traerlo alistado |
| -시- + **-아/어야 하다** | usted + tener que |

**El esqueleto:** 겨울옷과 양말을 준비해 오셔야 합니다 = «tienen que traer alistada la ropa de invierno y las medias».

⭐ **-아/어 오다 vs -아/어 가다**: 오다 trae la acción **hacia** aquí (준비해 오다 = alístalo allá y tráelo), 가다 la lleva **hacia** allá (사 가다 = cómpralo y llévatelo).

#### 8. 음식과 텐트는 모두 저희가 제공하니까 준비하실 필요가 없습니다.

| Pieza | Qué es |
|---|---|
| 음식 | comida |
| 텐트 | carpa (préstamo del inglés *tent*) |
| 모두 | todo, todos |
| **저희** | nosotros (humilde, ante un cliente) |
| 제공하다 | proveer, suministrar (提供) |
| **-(으)니까** | porque / así que (razón que lleva a una conclusión) |
| **-(으)ㄹ 필요가 없다** | no hay necesidad de |

**El esqueleto:** 저희가 제공하니까 준비하실 필요가 없습니다 = «como lo proveemos nosotros, no necesitan alistarlo».

⭐ Otro bloque con **가**, igual que el 수**가** 있다/없다 del 말하기: **필요가 없다** = «no existe la necesidad». 필요 es el sujeto de 없다. Apréndelo en bloque: 필요가 있다 / 필요가 없다.

### Párrafo 3

#### 9. 둘째 날 아침에는 낙타를 타고 사막을 산책하는 프로그램도 준비되어 있으니 원하시는 분은 따로 신청해 주세요.

| Pieza | Qué es |
|---|---|
| **둘째** 날 | el segundo día (둘째 = segundo, ordinal nativo) |
| 아침에는 | en la mañana (con 는 de contraste) |
| 낙타 | camello |
| 타다 → 타고 | montar → montando (acción con la que se hace la otra) |
| 사막을 산책하다 | pasear por el desierto |
| **-는 프로그램** | un programa que… |
| **도** | también |
| 준비되다 | estar/quedar preparado (준비하다 preparar → 준비되다 pasivo) |
| **-아/어 있다** | estado que sigue ahí → 준비되어 있다 = está listo |
| **-(으)니** | así que (versión corta y más formal de -(으)니까) |
| 원하다 → **원하시는 분** | desear → quien lo desee |
| **따로** | aparte, por separado |
| 신청하다 → **신청해 주세요** | inscribirse → háganme el favor de inscribirse |

**El esqueleto:** 프로그램도 준비되어 있으니 원하시는 분은 따로 신청해 주세요.

⭐ **-아/어 있다** (estado) ≠ **-고 있다** (acción en curso):
- 준비되**어 있다** = está listo (quedó así y sigue así).
- 준비하**고 있다** = lo están alistando ahora mismo.
- Otros: 앉아 있다 está sentado · 켜져 있다 está encendido · 열려 있다 está abierto.

#### 10. 사하라 여행사 드림

| Pieza | Qué es |
|---|---|
| 사하라 | Sáhara |
| 여행사 | agencia de viajes (旅行社: 여행 viaje + 社 empresa) |
| **드림** | «de parte de», atentamente (de 드리다 dar/ofrecer humilde) |

Es la **firma** de una carta formal. El molde es `<quien escribe> + 드림`. Con nombre de persona también existe **올림** (aún más humilde): 김유진 올림.

### Lo que hay que llevarse

| Coreano | Idea | Dónde sale |
|---|---|---|
| **N처럼** | como N (comparación) | 눈처럼 하얀 |
| **-는 / -(으)ㄴ + N** | modificador delante del sustantivo | 빛나는 사막, 하얀 모래 |
| **-(으)ㄹ 수 없는 + N** | N que no se puede… | 잊을 수 없는 하룻밤 |
| **-게 되다** | llegar a (sin forzarlo) | 보내시게 될 겁니다 |
| **-(으)ㄹ 겁니다** | futuro formal | 될 겁니다 |
| **-아/어 드리다** | hacerlo para un superior (humilde) | 보내 드리는, 알려 드리려고 |
| **-아/어 주시다** | háganme el favor de… | 봐 주시고, 신청해 주세요 |
| **N에 대한** | sobre N (+ sustantivo) | 여행에 대한 정보 |
| **-(으)려고 하다** | ir a, tener la intención de | 알려 드리려고 합니다 |
| **-(으)ㄴ/는 편이다** | más bien ser, tirar a | 건조한 편이지만 |
| **-기 좋다** | bueno para… | 여행하기 좋은 때 |
| **-아/어서** | porque (causa) | 일교차가 커서 |
| **N이/가 되면** | cuando llegue N | 밤이 되면 |
| **-(으)ㄹ 줄 모르다** ⭐ | no imaginarse que… | 추울 줄 모르고 |
| **만** | solo | 여름옷만 |
| **-아/어 오다** | traerlo ya hecho | 준비해 오셔야 |
| **-아/어야 하다** | tener que | 오셔야 합니다 |
| **-(으)니까 / -(으)니** | así que, porque | 제공하니까, 있으니 |
| **-(으)ㄹ 필요가 없다** | no hay necesidad de | 준비하실 필요가 없습니다 |
| **-아/어 있다** | estado que sigue | 준비되어 있으니 |
| **따로** | aparte | 따로 신청해 |
| **N 드림** | atentamente (firma) | 사하라 여행사 드림 |

**Dos irregulares que aparecen y hay que reconocer al vuelo:**
- **ㅂ irregular**: 춥다 → 추**울** 줄 (no 춥을).
- **ㅡ que se come**: 크다 → **커**서 (no 크어서).

**Y el patrón que se repite en toda la unidad:** `sustantivo + 가/이 + 있다/없다` como un solo bloque.
- 수**가** 있다/없다 = hay / no hay manera → 잊을 수 없는
- 필요**가** 없다 = no hay necesidad → 준비하실 필요가 없습니다
- 일교차**가** 크다 = la diferencia es grande

No memorices 수가 ni 필요가 como «palabra + partícula rara»: son el **sujeto** de 있다/없다/크다.
