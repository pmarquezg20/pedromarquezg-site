## Desglose completo

> [!info] De dónde sale
> Este desglose lo hizo ChatGPT a pedido de Pedro (17 sep 2026) y se guarda aquí tal cual, con el formato arreglado. La lógica que enseña —mirar la frase coreana por piezas, no traducirla de golpe— es la misma que usa el desglose de la lectura de la [[Korean 3/3A/Unidad 3/15 · 읽기|unidad 3]].

Estructuras que vale la pena entender aquí, varias ya vistas: **-느라고**, **-다가**, **-(으)ㄹ 때**, **-(으)ㄹ 거라고**, **-(으)ㄹ 수가 없다**, **대신**, **-(으)ㄹ 테니까**.

### 1. 미안해. 내가 너무 늦었지?

| Pieza | Qué es |
|---|---|
| 미안해 | perdón |
| 나 + 가 → **내가** | yo + sujeto |
| 너무 | demasiado |
| 늦다 → 늦었어 | llegar tarde / ser tarde → llegué tarde |
| **-지?** | ¿verdad?, ¿no? |

👉 «Llegué muy tarde, ¿verdad?». El **-지?** busca confirmación: la persona ya sabe que llegó tarde.

### 2. 지금이 몇 시니? 한 시간이나 늦게 오면 어떡해?

| Pieza | Qué es |
|---|---|
| 지금 | ahora |
| 몇 시 | qué hora |
| -이 | sujeto |
| **-니?** | pregunta informal |
| 한 시간 | una hora |
| **이나** | nada menos que, hasta, un montón de |
| 늦게 | tarde (adverbio) |
| 오다 → **오면** | venir → si/cuando viene (**-(으)면**) |
| 어떡해? | ¿qué hacemos?, ¿cómo puede ser? |

👉 지금이 몇 시니? = literalmente «¿qué hora es ahora?», pero por el tono es «¿¡tú sabes qué hora es!?».
👉 한 시간이나 늦게 오면 어떡해? = «¿cómo puedes llegar una hora tarde?».

⭐ **한 시간이나**: el 이나 enfatiza la cantidad.
- 한 시간 늦었어 = llegué una hora tarde.
- 한 시간**이나** 늦었어 = llegué **nada menos que** una hora tarde («¡una hora entera!»).

### 3. 나도 어쩔 수가 없었어. 택시를 탔는데 길이 너무 막혔어.

| Pieza | Qué es |
|---|---|
| 나도 | yo también |
| **어쩔 수가 없다** | no poder hacer nada, no tener otra opción |
| 없었어 | no había, no pude |
| 택시 | taxi |
| 타다 | subirse a, tomar (transporte) |
| **-는데** | pero, y resulta que (da contexto) |
| 길 | camino, vía |
| **막히다** | estar tapado, haber trancón |
| 너무 | demasiado |

👉 나도 어쩔 수가 없었어 = «yo tampoco pude hacer nada / no me quedó otra».
👉 택시를 탔는데 길이 너무 막혔어 = «tomé un taxi, pero había muchísimo tráfico».

⭐ ¿Y otra vez ese 가 en 수가? La estructura es **어쩔 수가 없다**: 어쩌다 (hacer algo al respecto) + 수 (manera, posibilidad) + **가** (marca 수 como sujeto) + 없다 (no existir). Literalmente: «no existe una manera».

### 4. 왜 택시를 탔어? 퇴근 시간엔 언제나 길 막히는 거 몰랐어?

| Pieza | Qué es |
|---|---|
| 왜 | por qué |
| 탔어 | tomaste, te subiste |
| **퇴근** | salir del trabajo (退勤) |
| 시간 | hora |
| 퇴근 시간 | la hora de salida, la hora pico |
| **엔** | 에 + 는 (en ese momento, en cambio) |
| 언제나 | siempre |
| 길 막히는 | que hay trancón |
| **거** | 것 = cosa, hecho |
| 몰랐어? | ¿no sabías? |

👉 «¿Por qué tomaste taxi? ¿No sabías que a la hora de salida siempre hay trancón?»

⭐ El molde es **`-는 거 몰랐어?`** = «¿no sabías que…?». En conversación 것 se dice **거**: 먹는 거 (lo que comes), 좋아하는 거 (lo que te gusta), 길 막히는 거 (el hecho de que hay trancón). La forma completa sería 길이 막히는 **것을** 몰랐어?

### 5. 실은 어제 숙제하느라고 못 자서 낮에 깜빡 잠이 들었어. ⭐

La frase más importante del diálogo: aquí está la gramática de la unidad.

| Pieza | Qué es |
|---|---|
| **실은** | en realidad, la verdad es que |
| 어제 | ayer |
| 숙제하다 | hacer la tarea |
| **-느라고** | por estar haciendo X, pasó algo negativo |
| 못 자다 | no poder dormir |
| **-아/어서** | porque, así que |
| 낮에 | durante el día |
| **깜빡** | por un descuido, sin darse cuenta |
| **잠이 들다** | quedarse dormido (entrar en el sueño) |

👉 «La verdad es que ayer no pude dormir por estar haciendo la tarea, así que durante el día me quedé dormido sin darme cuenta».

⭐ **A-느라고 B**: estaba ocupado en A, y por eso ocurrió B (normalmente algo malo). 숙제하느라고 못 잤어 = por estar haciendo la tarea no dormí.

⭐ **자다 ≠ 잠이 들다**: 자다 es dormir; **잠이 들다** es *quedarse* dormido, el momento de caer. Otro bloque de los de `sustantivo + 이/가 + verbo`.

### 6. 택시를 타면 빨리 올 수 있을 거라고 생각했는데…….

| Pieza | Qué es |
|---|---|
| 타다 → **타면** | tomar → si tomaba |
| 빨리 | rápido, pronto |
| 오다 | venir |
| **올 수 있다** | poder venir |
| 올 수 있을 거야 | podré venir (suposición) |
| **-(으)ㄹ 거라고** | que iba a… (lo convierte en lo que uno pensaba o decía) |
| 생각하다 | pensar |
| **-는데…** | pero… (queda en suspenso) |

La cadena, paso a paso:
`오다` → `올 수 있다` (poder venir) → `올 수 있을 거야` (podré venir) → `올 수 있을 거라고 생각했어` (pensé que podría venir).

👉 «Pensé que tomando taxi llegaría rápido, pero…». Queda incompleta a propósito: está pidiendo perdón sin decirlo.

### 7. 나는 여기 오느라고 개강 파티에도 못 갔는데 어떻게 이럴 수가 있어?

¡**-느라고** otra vez!

| Pieza | Qué es |
|---|---|
| 여기 | aquí |
| **오느라고** | por venir acá |
| **개강** | inicio del semestre (開講) |
| 파티 | fiesta |
| 개강 파티 | fiesta de inicio de semestre |
| **에도** | ni siquiera a, también a |
| 못 갔어 | no pude ir |
| 어떻게 | cómo |
| 이렇다 → **이럴** | ser así → que sea así |
| **수가 있어?** | ¿existe la posibilidad? |

👉 «Yo por venir acá ni siquiera fui a la fiesta de inicio de semestre, ¿cómo puedes hacer esto?»

⭐ **어떻게 이럴 수가 있어?** es muy coreano. Literalmente «¿cómo puede existir la posibilidad de que esto sea así?», en la práctica «¿cómo puede ser algo así?». Con indignación.
- 이럴 수 있어? = ¿puede pasar esto?
- 어떻게 이럴 **수가** 있어? = ¿¡cómo puede ser posible algo así!?

### 8. 정말 미안해. 대신 내가 맛있는 저녁 사 줄 테니까 그만 화 풀어.

| Pieza | Qué es |
|---|---|
| 정말 | de verdad |
| **대신** | a cambio, en compensación |
| 맛있는 | rico, delicioso |
| 저녁 | cena |
| 사다 | comprar |
| **사 주다** | invitar (comprarle algo a alguien) |
| **-(으)ㄹ 테니까** | como voy a hacer X, entonces… |
| 그만 | ya basta de |
| 화 | rabia, enojo |
| **화를 풀다** | calmarse, soltar la rabia |

👉 «De verdad perdón. A cambio yo te invito una buena comida, así que ya no estés bravo».

⭐ **-(으)ㄹ 테니까** = promesa + razón: 사 줄 테니까 = «como yo voy a invitar…». Se usa para convencer.
⭐ En hablado se cae la partícula: 화**를** 풀어 → 화 풀어.

### 9. 늦을 때마다 미안하다고만 하지 말고 늦게 오는 버릇 좀 고쳐.

| Pieza | Qué es |
|---|---|
| 늦다 → **늦을 때** | llegar tarde → cuando llegas tarde |
| **-마다** | cada, cada vez que |
| 미안하다 | sentirlo |
| **-다고** | que… (cita lo dicho) |
| **-만** | solamente |
| **-지 말고** | no hagas X, y en cambio… |
| 늦게 오는 | que llega tarde |
| **버릇** | hábito, costumbre |
| 좀 | un poco (suaviza la orden) |
| **고치다** | corregir, arreglar |

👉 «Cada vez que llegas tarde no te limites a decir “perdón”: corrige de una vez ese hábito de llegar tarde».

⭐ **-다고만 하지 말고** = «no te limites a decir que…». Y **버릇을 고치다** es el verbo que va con hábito: corregirlo.

### Lo que hay que llevarse

| Coreano | Idea |
|---|---|
| **-지?** | ¿verdad? |
| **-(이)나** | nada menos que, hasta |
| **어쩔 수가 없다** | no hay nada que hacer |
| **-는데** | pero, contexto, resulta que |
| **-느라고** ⭐ | por estar haciendo X, pasó algo negativo |
| **-아/어서** | porque, así que |
| **깜빡** | sin darse cuenta, por descuido |
| **잠이 들다** | quedarse dormido |
| **-(으)ㄹ 수 있다** | poder |
| **-(으)ㄹ 거라고 생각하다** | pensar que… |
| **-에도** | ni siquiera a, también a |
| **어떻게 이럴 수가 있어?** | ¿cómo puede ser esto posible? |
| **대신** | a cambio, en compensación |
| **-(으)ㄹ 테니까** | como voy a…, entonces… |
| **화를 풀다** | dejar de estar bravo |
| **-마다** | cada vez que |
| **-다고만 하다** | limitarse a decir que… |
| **버릇을 고치다** | corregir un hábito |

**El patrón que se repite muchísimo:** `수` **+ 가 +** `있다/없다`.
- 할 수가 없어 = no puedo hacerlo
- 어쩔 수가 없어 = no hay nada que pueda hacer
- 이럴 수가 있어? = ¿cómo puede ser posible?

Ese 가 tiene sentido: **수** es el **sujeto** de 있다/없다. 수가 있다 = existe una posibilidad; 수가 없다 = no existe. No lo memorices como «수 + partícula rara»: aprende **수가 있다/없다** como un bloque.
