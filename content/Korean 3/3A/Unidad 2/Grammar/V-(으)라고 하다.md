# Grammar 2 - V-(으)라고 하다

Unidad: [[Korean 3/3A/Unidad 2/Index - Unidad 2|Unidad 2: 방을 바꿔 달라고 해 봐]]
Fuente: Student Book 3A (p. 49 + appendix p. 243) + audios de la app koreano.
Seccion: 문법

## La idea clave
`V-(으)라고 하다` = **Cita indirecta de una orden o un favor**

Para repetir lo que alguien te MANDÓ o te PIDIÓ. Lo clave son las tres variantes: si el favor es para el que habla → -아/어 달라고 하다 (달라); si es para un tercero → -아/어 주라고 하다 (주라); y la negación es -지 말라고 하다.

## Forma
`V-(으)라고 했어요 | favor para mí: -아/어 달라고 했어요 | favor para otro: -아/어 주라고 했어요 | negativo: -지 말라고 했어요`

|  | 받침 X | 받침 O |
|---|---|---|
| 동사 | 보내다 → 보내라고 했어요 | 읽다 → 읽으라고 했어요 |

| Coreano | Español |

| 동생한테 청소하라고 했어요. | Le dije a mi hermano que limpiara. |

## Appendix del libro (문법 해설)
**Significado (p. 243):** 명령이나 부탁을 다른 사람에게 전달할 때 사용한다. (cita indirecta de imperativo)

**Combinación:** 동사

Ejemplos del appendix:

- `친구에게 이메일을 보내라고 했어요.`
- `언니가 이 책을 읽으라고 했어요.`

**주의 / '-아/어 주세요' 명령문: si el que habla y el beneficiario son la MISMA persona → '-아/어 달라고 하다'; si son DISTINTAS → '-아/어 주라고 하다'.**

- `마이클: '물 좀 주세요.' → 마이클 씨가 (나에게) 물 좀 달라고 했어요.`
- `마이클: '윌슨 씨에게 물 좀 주세요.' → 마이클 씨가 윌슨 씨에게 물 좀 주라고 했어요.`
- `'소금 좀 주세요.' → 소금 좀 달라고 했어요.`
- `'돈을 좀 빌려주세요.' → 돈을 좀 빌려 달라고 했어요.`
- `'이 책을 마이클 씨에게 주세요.' → 이 책을 마이클 씨에게 주라고 했어요.`

**주의 / 부정형: '-지 말라고 하다'.**

- `어머니가 아이에게 뛰지 말라고 했어요.`
- `선생님이 교실에서 영어로 이야기하지 말라고 하셨어요.`

## Errores típicos de hispanohablantes
- El lío de 달라 vs 주라: si el favor es para el que habla → `달라고`; si es para otro → `주라고`.
- Negar con `-지 않으라고`: ✗ → `-지 **말**라고 했어요`.

## Machete para Pedro
`V-(으)라고 했어요`

- 기숙사 조교한테 방을 바꿔 달라고 했어. → *Le pedí al monitor de la residencia que me cambiara de cuarto.*
- 어머니께서 게임을 하지 말라고 하셨어요. → *Mi mamá me dijo que no jugara videojuegos.*
- 선생님께서 나나 씨에게 책을 보여 주라고 하셨어요. → *El profesor dijo que le mostrara el libro a Nana.*
- 룸메이트 때문에 힘들 때 어떻게 했어? → *Cuando te tocaba duro por el compañero, ¿qué hiciste?*
