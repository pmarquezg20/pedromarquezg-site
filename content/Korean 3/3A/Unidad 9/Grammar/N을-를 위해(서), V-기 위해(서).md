# Grammar 1 - N을/를 위해(서), V-기 위해(서)

Unidad: [[Korean 3/3A/Unidad 9/Index - Unidad 9|Unidad 9: 한글날에 대해 들어 봤어요?]]
Fuente: Student Book 3A (p. 216 + appendix p. 261) + audios de la app koreano.
Seccion: 문법

## La idea clave
`N을/를 위해(서), V-기 위해(서)` = **"Para..." (propósito, formal)**

El propósito de una acción. Es la versión escrita y formal de -(으)려고, así que es la que te sirve en el 쓰기 y en una presentación. Con adjetivos NO va directo: se pasa a adverbio (건강하게 살기 위해) o a sustantivo (건강을 위해).

## Forma
`N을/를 위해(서) (부모님 → 부모님을 위해서) · V-기 위해(서) (벌다 → 벌기 위해서)`

|  | 받침 X | 받침 O |
|---|---|---|
| 명사 | 어린이 → 어린이를 위해서 | 부모님 → 부모님을 위해서 |
| 동사 | 유학하다 → 유학하기 위해서 | 돈을 벌다 → 돈을 벌기 위해서 |

## Ejemplos del libro (예문)
Dialogo de la caja (track 90):

| Coreano | Español |
|---|---|
| A: 어버이날 선물을 사려고 하는데요. |  |
| B: 이 홍삼 제품은 어떠세요? 요즘 부모님의 건강을 위해서 건강식품 선물을 많이 하세요. |  |

예 (ejemplos bajo la caja):

| Coreano | Español |
|---|---|
| 건강을 위해 열심히 운동해요. |  |
| 군인은 나라를 위해서 싸워요. |  |
| 생활비를 벌기 위해 아르바이트를 해요. | Trabajo por horas para ganar lo del diario. |
| 독감에 걸리지 않기 위해서 예방 주사를 맞아요. | Me vacuno para no coger gripa. |

## Appendix del libro (문법 해설)
**Significado (p. 261):** 행동의 목적을 나타낼 때 쓴다. (para, con el fin de)

**Combinación:** 명사, 동사

Ejemplos del appendix:

- `군인은 나라를 위해서 목숨을 바친다.`
- `아버지는 가족을 위해서 일을 하신다.`
- `시장 조사를 하기 위해서 미국으로 출장을 갔다.`
- `집을 새로 짓기 위해서 필요한 재료를 알아봤다.`

**주의 / Es más escrito y formal que '-(으)려고'; encaja mejor en el 쓰기 y en situaciones oficiales.**

- `한국말을 배우기 위해서 한국에 왔습니다. (formal)`
- `한국어를 배우려고 한국에 왔어요. (hablado)`

**주의 / Con adjetivos lo natural es adverbializarlos ('건강하게 살기 위해') o usar el sustantivo ('건강을 위해').**

- `건강을 위해 아침마다 30분씩 운동을 합니다. (O)`
- `건강하게 살기 위해 아침마다 30분씩 운동을 합니다. (O)`
- `건강하기 위해 아침마다 30분씩 운동을 합니다. (X)`

## Errores típicos de hispanohablantes
- Ponerlo directo con adjetivo: ✗ `건강하기 위해` → `건강**을** 위해` o `건강하**게 살기** 위해`.
- Usarlo en conversación casual: ahí suena tieso; va `-(으)려고`.
- Olvidar el 을/를 con sustantivo: ✗ `나라 위해` → `나라**를** 위해`.

## Machete para Pedro
`N을/를 위해(서) (부모님 → 부모님을 위해서) · V-기 위해(서) (벌다 → 벌기 위해서)`

- 요즘 부모님의 건강을 위해서 건강식품 선물을 많이 하세요. → *Últimamente la gente regala mucho alimento saludable para la salud de los papás.*
- 생활비를 벌기 위해 아르바이트를 해요. → *Trabajo por horas para ganar lo del diario.*
- 독감에 걸리지 않기 위해서 예방 주사를 맞아요. → *Me vacuno para no coger gripa.*
- 나라를 위해 싸우다가 돌아가신 분들을 기억하기 위해 만들어진 날이지요. → *Es un día creado para recordar a quienes murieron peleando por el país.*

1. `요즘 부모님의 건강을 위해서 건강식품 선물을 많이 하세요.`
   Últimamente la gente regala mucho alimento saludable para la salud de los papás.

   Trabajo por horas para ganar lo del diario.

3. `독감에 걸리지 않기 위해서 예방 주사를 맞아요.`
   Me vacuno para no coger gripa.

4. `나라를 위해 싸우다가 돌아가신 분들을 기억하기 위해 만들어진 날이지요.`
   Es un día creado para recordar a quienes murieron peleando por el país.
