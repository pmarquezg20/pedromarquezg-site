# Grammar 4 - N(이)라도

Unidad: [[Korean 3/3A/Unidad 5/Index - Unidad 5|Unidad 5: 입어 보고 살걸 그랬어요]]
Fuente: Student Book 3A (p. 125 + appendix p. 252) + audios de la app koreano.
Seccion: 문법

## La idea clave
`N(이)라도` = **"Aunque sea..." (lo último que queda)**

No es lo que querías, pero no queda de otra. La diferencia con N(이)나 (unidad 4) es de fuerza: (이)나 es una segunda opción aceptable, (이)라도 es la última que queda. Si solo te quedan 10.000 wones, va 만 원이라도 빌려줘, no 만 원이나.

## Forma
`받침 X: N라도 (커피 → 커피라도) · 받침 O: N이라도 (빵 → 빵이라도)`

|  | 받침 X | 받침 O |
|---|---|---|
| 명사 | 커피 → 커피라도 | 빵 → 빵이라도 |

## Appendix del libro (문법 해설)
**Significado (p. 252):** 마음에 안 들지만 상황이 어쩔 수 없어서 차선이라도 선택할 때 쓴다. (ya que no hay otra, aunque sea…)

**Combinación:** 명사

Ejemplos del appendix:

- `출장 왔는데 구경할 시간이 조금밖에 없군요. - 그럼 시내라도 구경합시다.`
- `손님, 통로 쪽 좌석밖에 없는데요. - 그럼 그거라도 주세요.`
- `지금 커피가 다 떨어졌는데 녹차라도 드릴까요?`
- `아직 일이 안 끝나서 조금 기다려야 하는데 심심해서 잡지라도 읽고 있어.`

**주의 / COMPARACIÓN con 'N(이)나' (3급 4과): los dos sirven para una propuesta suave, pero '(이)라도' marca con más fuerza que es la ÚLTIMA opción que queda; '(이)나' es una segunda opción aceptable, no la última.**

- `A: 밥이 없는데 어떡하지? B: 그럼 라면이나 끓여 주세요. (O)`
- `A: 라면도 다 떨어졌어. 과자밖에 없는데. B: 그럼 과자라도 주세요. (O)`
- `A: 지금 만 원밖에 없는데. B: 그럼 만 원이라도 빌려줘. (O) / 만 원이나 빌려줘. (X)`

## Errores típicos de hispanohablantes
- Usarlo cuando sí hay más opciones: ahí va `(이)나`.
- Usarlo con algo que es tu primera opción: suena a desprecio.
- Olvidar el (이) tras 받침: ✗ `빵라도` → `빵**이**라도`.

## Machete para Pedro
`받침 X: N라도 (커피 → 커피라도) · 받침 O: N이라도 (빵 → 빵이라도)`

- 그럼 교환이라도 해 주세요. → *Entonces cámbiemelo, aunque sea.*
- 지금 커피가 다 떨어졌는데 녹차라도 드릴까요? → *Se acabó el café; ¿le sirvo aunque sea un té verde?*
- 집에 따뜻한 밥이 없는데 찬밥이라도 먹을래? → *No hay arroz caliente en la casa, ¿comes aunque sea del frío?*
- 고객님, 확인해 보니 회색밖에 안 남았는데 이거라도 드릴까요? → *Señora, revisé y solo queda el gris; ¿le doy este aunque sea?*

## Mini-drill para 빽빽이 corto
1. `그럼 교환이라도 해 주세요.`
   Entonces cámbiemelo, aunque sea.

2. `지금 커피가 다 떨어졌는데 녹차라도 드릴까요?`
   Se acabó el café; ¿le sirvo aunque sea un té verde?

3. `집에 따뜻한 밥이 없는데 찬밥이라도 먹을래?`
   No hay arroz caliente en la casa, ¿comes aunque sea del frío?

4. `고객님, 확인해 보니 회색밖에 안 남았는데 이거라도 드릴까요?`
   Señora, revisé y solo queda el gris; ¿le doy este aunque sea?
