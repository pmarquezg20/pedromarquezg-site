## 연습 2 · p.175 · 수리 센터 (va para el parcial de 말하기)

La profesora dijo que esto sale en el parcial: te dan un aparato dañado de la unidad y haces el diálogo, de cliente o de empleado. Es el mismo diálogo del Track 73, pero con tu aparato y tu problema. Cuatro pasos:

1. **Saludo** (empleado): `어서 오세요. 뭘 도와드릴까요?`
2. **El aparato** (cliente): `____이/가 고장 나서 왔는데요.` → `휴대폰이 고장 나서 왔는데요.`
3. **El síntoma** (empleado pregunta `어떻게 안되세요?`; cliente responde con `-더니`): `어제까지 잘되더니 오늘 아침부터 안돼요.` + el síntoma.
4. **Las preguntas del 수리 신청서** (empleado) y las respuestas (cliente). Cierre: `바로 접수해 드리도록 하겠습니다.`

### Los síntomas, por aparato (vocabulario de la 7과)

| Aparato | Síntoma | Traducción |
|---|---|---|
| 휴대폰 | 화면이 안 나와요 / 액정이 나갔어요 | no da imagen / se dañó la pantalla |
| 휴대폰 | 전화가 자꾸 끊겨요 | la llamada se corta a cada rato |
| 휴대폰 | 전원이 자꾸 꺼져요 | se apaga solo a cada rato |
| 휴대폰 | 충전이 안돼요 / 배터리가 금방 닳아요 | no carga / la batería se gasta rápido |
| 세탁기 | 탈수가 안돼요 | no centrifuga |
| 세탁기 | 이상한 소리가 나요 (윙 소리가 나요) | hace un ruido raro (un zumbido) |
| 세탁기 | 세탁기가 심하게 흔들려요 | se sacude muy fuerte |
| 냉장고 | 온도 조절이 안돼요 | no regula la temperatura |
| 냉장고 | 채소가 얼어요 | se congelan las verduras |
| 에어컨 | 찬 바람이 안 나와요 | no sale aire frío |
| 복사기 | 종이가 자꾸 걸려요 | el papel se atasca a cada rato |
| 복사기 | 복사가 흐려져요 | las copias salen borrosas |
| 리모컨 | 버튼을 눌러도 안돼요 | aunque oprima el botón no funciona |
| 노트북 | 전원이 안 들어와요 | no prende |

### 확인 사항 · las preguntas y cómo contestarlas

| Pregunta (empleado) | Traducción | Sí | No |
|---|---|---|---|
| 물에 빠뜨렸습니까? | ¿Se le cayó al agua? | 네, 지난주에 물에 빠뜨렸어요. | 아니요, 물에 빠뜨린 적은 없어요. |
| 떨어뜨린 적이 있습니까? | ¿Se le ha caído alguna vez? | 네, 며칠 전에 한 번 떨어뜨렸어요. | 아니요, 떨어뜨린 적 없어요. |
| 혹시 음료수를 쏟았습니까? | ¿De pronto le regó una bebida? | 네, 커피를 좀 쏟았어요. | 아니요, 쏟은 적 없는데요. |
| 플러그를 빼 놓지 않았습니까? | ¿No será que lo dejó desenchufado? | 아, 플러그를 빼 놓았네요. | 아니요, 플러그는 잘 꽂혀 있어요. |
| 기계 안에 먼지가 끼어 있습니까? | ¿Tiene polvo acumulado adentro? | 네, 먼지가 좀 끼어 있는 것 같아요. | 아니요, 먼지는 없어요. |

Ojo con la gramática de las preguntas: `-(으)ㄴ 적이 있다` (alguna vez), `-아/어 놓다` (dejar hecho: 빼 놓다 = dejar desenchufado), `-아/어 있다` (estado: 끼어 있다, 꽂혀 있다).

### Para cerrar (lo que falta en el libro y siempre preguntan)

- `수리하는 데 얼마나 걸려요?` · ¿Cuánto se demora la reparación? → `일주일쯤 걸릴 거예요. 다 되면 연락 드릴게요.`
- `수리비는 얼마예요?` · ¿Cuánto cuesta? → `고쳐 봐야 알 수 있어요.` (hay que revisarlo primero) / `3만 원쯤 될 거예요.`
- `네, 알겠습니다. 바로 접수해 드리도록 하겠습니다.` · Entendido, se lo radico de una vez.
