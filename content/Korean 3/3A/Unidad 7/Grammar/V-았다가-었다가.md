# Grammar 1 - V-았다가/었다가

Unidad: [[Korean 3/3A/Unidad 7/Index - Unidad 7|Unidad 7: 껐다가 다시 켜 보세요]]
Fuente: Student Book 3A (p. 168 + appendix p. 255) + audios de la app koreano.
Seccion: 문법

## La idea clave
`V-았다가/었다가` = **"Lo hice y después..." (acción terminada, luego otra)**

La primera acción TERMINA completa y luego viene otra, normalmente la contraria. La diferencia con -다가 (2급 7과) es esa: 시장에 갔다가 = ya llegó al mercado; 시장에 가다가 = iba de camino. Dos condiciones: mismo sujeto, y verbos opuestos o relacionados.

## Forma
`ㅏ/ㅗ: -았다가 (가다→갔다가) · 하다: 했다가 · resto: -었다가 (쓰다→썼다가)`

|  |  |
|---|---|
| ㅏ, ㅗ | 가다 → 갔다가 |
| 하다 | 하다 → 했다가 |
| ㅓ, ㅜ, ㅣ 등 | 쓰다 → 썼다가 |

## Appendix del libro (문법 해설)
**Significado (p. 255):** 하나의 동작이 끝난 후에 다른 동작으로 전환함을 나타낸다. (terminar una acción y pasar a otra)

**Combinación:** 동사

Ejemplos del appendix:

- `학교에 갔다가 머리가 아파서 집에 일찍 돌아왔어요.`
- `약속했다가 급한 일이 있어서 취소했어요.`
- `편지를 썼다가 찢어 버렸어요.`

**주의 / El sujeto de las dos partes tiene que ser el MISMO.**

- `나는 불을 껐다가 다시 켰어요. (O)`
- `나는 불을 껐다가 동생이 다시 켰어요. (X)`

**주의 / Los dos verbos deben ser opuestos o estar relacionados.**

- `문을 열었다가 닫았다. (O)`
- `신발을 신었다가 벗었다. (O)`
- `신발을 신었다가 들어갔다. (X)`

**주의 / COMPARACIÓN con 'V-다가' (2급 7과): '-았다가' = la primera acción TERMINÓ y luego viene otra; '-다가' = la primera se INTERRUMPE a mitad.**

- `시장에 갔다가 급한 약속이 생각나서 학교에 갔다. (ya llegó al mercado)`
- `시장에 가다가 급한 약속이 생각나서 학교에 갔다. (iba de camino)`
- `밥을 먹었다가 전화를 받았어요. (X) / 밥을 먹다가 전화를 받았어요. (O)`

## Errores típicos de hispanohablantes
- Sujetos distintos: ✗ `나는 불을 껐다가 동생이 켰어요`.
- Verbos sin relación: ✗ `신발을 신었다가 들어갔다` → `신었다가 **벗었다**`.
- Confundirlo con `-다가` (2급 7과): ese interrumpe la acción, este la termina.

## Machete para Pedro
`ㅏ/ㅗ: -았다가 (가다→갔다가) · 하다: 했다가 · resto: -었다가 (쓰다→썼다가)`

- 그럼 껐다가 다시 켜 보세요. → *Entonces apáguelo y vuelva a encenderlo.*

- 편지를 썼다가 마음에 안 들어서 찢어 버렸어요. → *Escribí una carta y como no me gustó la rompí.*
