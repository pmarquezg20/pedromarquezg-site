# Grammar 1 - A-다고 하다, V-ㄴ다고/는다고 하다, N(이)라고 하다

Unidad: [[Korean 3/3A/Unidad 1/Index - Unidad 1|Unidad 1: 신입생 환영회를 한다고 해요]]
Fuente: Student Book 3A (p. 26 + appendix p. 241) + audios de la app koreano.
Seccion: 문법

## La idea clave
`A-다고 하다, V-ㄴ다고/는다고 하다, N(이)라고 하다` = **Cita indirecta: "dicen que..."**

Repite lo que otra persona (o un medio) dijo. El coreano no usa comillas: mete la frase citada dentro de la oración y le pega -다고 하다. Ojo con el verbo: el adjetivo va tal cual (바쁘다고), pero el VERBO añade ㄴ/는 (간다고, 먹는다고), y el sustantivo lleva (이)라고.

## Forma
`A-다고 해요 · V-ㄴ다고/는다고 해요 · N(이)라고 해요 | Pasado: -았/었다고 해요 | Futuro: -(으)ㄹ 거라고 해요`

|  | 받침 X | 받침 O |
|---|---|---|
| 형용사 | 바쁘다 → 바쁘다고 해요 | 어렵다 → 어렵다고 해요 |
| 동사 | 가다 → 간다고 해요 | 먹다 → 먹는다고 해요 |
| 명사 | 학교 → 학교라고 해요 | 책 → 책이라고 해요 |

## Ejemplos del libro (예문)
Dialogo de la caja (track 03):

| Coreano | Español |
|---|---|
| A: 게시판 봤어요? | ¿Viste la cartelera? |
| B: 네, 신입생 환영회를 한다고 해요. | Sí, dicen que van a hacer la fiesta de bienvenida. |

예 (ejemplos bajo la caja):

| Coreano | Español |
|---|---|
| 크리스 씨는 요즘 바쁘다고 해요. | Dicen que Chris anda ocupado últimamente. |
| 마이클 씨는 모임에 참석 못 한다고 했어요. | Michael dijo que no puede ir a la reunión. |
| 민수 씨 동생은 고등학생이라고 해요. | Dicen que el hermano de Minsu es de bachillerato. |

## Appendix del libro (문법 해설)
**Significado (p. 241):** 다른 사람이나 매체를 통해 알게 된 내용을 옮겨 전달할 때 사용한다. (cita indirecta)

**Combinación:** 형용사, 동사, 명사

Ejemplos del appendix:

- `수지는 경제학 공부가 어렵다고 했어요.`
- `모모코 씨는 매주 일요일에 교회에 간다고 해요.`
- `사우드 씨는 돼지고기를 안 먹는다고 했어요.`
- `여기가 영희 씨가 졸업한 학교라고 해요.`
- `동생은 생일에 받고 싶은 선물이 소설책이라고 했어요.`

**주의 / Si lo citado va en PASADO: -았다고/었다고 하다, -이었다고/였다고 하다**

|  |  |
|---|---|
| 형용사 | 예뻤다 → 예뻤다고 해요 |
| 동사 | 갔다 → 갔다고 해요 |
| 명사 받침X | 학교 → 학교였다고 해요 |
| 명사 받침O | 중학생 → 중학생이었다고 해요 |

- `아버지는 어머니가 젊었을 때 정말 예뻤다고 항상 말씀하세요.`
- `레이 씨가 엔 씨는 수영장에 갔다고 했어요.`
- `이 공원은 옛날에 대학교였다고 해요.`
- `그 사람을 처음 만난 날은 일요일이었다고 해요.`

**주의 / Si lo citado va en FUTURO: -(으)ㄹ 거라고 하다 / -겠다고 하다**

|  |  |
|---|---|
| 형용사 | 춥다 → 추울 거라고 해요 / 춥겠다고 해요 |
| 동사 | 먹다 → 먹을 거라고 해요 / 먹겠다고 해요 |


## Errores típicos de hispanohablantes
- Poner el adjetivo como si fuera verbo: ✗ `바쁜다고 해요` → `바쁘**다**고 해요`. Solo el VERBO lleva ㄴ/는.
- Olvidar el (이) del sustantivo: ✗ `고등학생라고` → `고등학생**이**라고`.
- Meter el pasado en el 하다 en vez de en lo citado: ✗ `간다고 했었어요` para 'dijo que fue' → `**갔다**고 했어요`.
