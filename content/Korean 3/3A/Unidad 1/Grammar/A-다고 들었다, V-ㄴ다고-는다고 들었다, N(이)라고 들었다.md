# Grammar 3 - A-다고 들었다, V-ㄴ다고/는다고 들었다, N(이)라고 들었다

Unidad: [[Korean 3/3A/Unidad 1/Index - Unidad 1|Unidad 1: 신입생 환영회를 한다고 해요]]
Fuente: Student Book 3A (p. 30 + appendix p. 242) + audios de la app koreano.
Seccion: 문법

## La idea clave
`A-다고 들었다, V-ㄴ다고/는다고 들었다, N(이)라고 들었다` = **"Escuché que..."**

Igual que -다고 하다 pero marcando que la información la OÍSTE, no que alguien concreto la dijo. Es el que más te va a servir para hablar de Corea: 서울이 복잡하다고 들었어요.

## Forma
`A-다고 들었어요 · V-ㄴ다고/는다고 들었어요 · N(이)라고 들었어요`

|  | 받침 X | 받침 O |
|---|---|---|
| 형용사 | 복잡하다 → 복잡하다고 들었어요 | 맵다 → 맵다고 들었어요 |
| 동사 | 가다 → 간다고 들었어요 | 먹다 → 먹는다고 들었어요 |
| 명사 | 학교 → 학교라고 들었어요 | 쉬는 날 → 쉬는 날이라고 들었어요 |

## Ejemplos del libro (예문)
Dialogo de la caja (track 06):

| Coreano | Español |
|---|---|
| A: 다음 학기에 무슨 강의 들을까? | ¿Qué materia tomo el semestre que viene? |
| B: '한국 문화'라는 강의가 좋다고 들었어. | Escuché que la materia 'Cultura coreana' es buena. |

예 (ejemplos bajo la caja):

| Coreano | Español |
|---|---|
| 수미 씨가 요즘 회사 일 때문에 바쁘다고 들었어요. | Escuché que Sumi anda ocupada por el trabajo. |
| 다니엘 씨가 방학에 고향에 간다고 들었어요. |  |
| 한국 사람들은 매일 김치를 먹는다고 들었는데 맞아요? | Escuché que los coreanos comen kimchi todos los días, ¿es cierto? |
| 10월 9일이 한글날이라고 들었어요. |  |

## Appendix del libro (문법 해설)
**Significado (p. 242):** 다른 사람이나 매체를 통해 들은 내용을 옮겨 전달할 때 사용한다. (cita de algo OÍDO)

**Combinación:** 형용사, 동사, 명사

Ejemplos del appendix:

- `서울이 복잡하다고 들었어요.`
- `마이클 씨가 고향에 간다고 들었어요.`
- `투투 씨가 불고기를 잘 먹는다고 들었어요.`
- `내일이 쉬는 날이라고 들었어요.`

**주의 / Pasado: -았다고/었다고 들었다 · Futuro: -(으)ㄹ 거라고 들었다**

|  |  |  |
|---|---|---|
| 형용사 | 재미있었다 → 재미있었다고 들었어요 | 추울 것이다 → 추울 거라고 들었어요 |
| 동사 | 갔다 → 갔다고 들었어요 | 먹을 것이다 → 먹을 거라고 들었어요 |

- `영화가 재미있었다고 들었어요.`
- `마이클 씨가 고향에 갔다고 들었어요.`
- `내일 날씨가 추울 거라고 들었어요.`
- `저녁에 삼겹살을 먹을 거라고 들었어요.`

**주의 / Parecidos a '-다고 하다': '-다고 말하다', '-다고 그랬다'. Para opinión o pensamiento propio: '-다고 생각하다'.**


## Errores típicos de hispanohablantes
- Usar `-다고 들었다` cuando la fuente es una persona concreta que te habló: ahí queda mejor `-다고 했어요`.
- El mismo error de siempre: adjetivo sin ㄴ/는, verbo con ㄴ/는.

## Machete para Pedro
`A-다고 들었어요 · V-ㄴ다고/는다고 들었어요 · N(이)라고 들었어요`

- '한국 문화'라는 강의가 좋다고 들었어. → *Escuché que la materia 'Cultura coreana' es buena.*
- 서울이 복잡하다고 들었어요. → *Escuché que Seúl es caótico.*
- 내일이 쉬는 날이라고 들었어요. → *Escuché que mañana es día de descanso.*
- 내일 날씨가 추울 거라고 들었어요. → *Escuché que mañana va a hacer frío.*
