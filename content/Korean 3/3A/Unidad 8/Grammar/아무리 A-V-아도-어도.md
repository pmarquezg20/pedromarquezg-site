# Grammar 3 - 아무리 A/V-아도/어도

Unidad: [[Korean 3/3A/Unidad 8/Index - Unidad 8|Unidad 8: 교통사고가 났다고요?]]
Fuente: Student Book 3A (p. 196 + appendix p. 259) + audios de la app koreano.
Seccion: 문법

## La idea clave
`아무리 A/V-아도/어도` = **"Por más que..."**

Enfatiza que aunque la cosa sea extrema, el resultado no cambia. Va siempre con 아무리 adelante y -아도/어도 atrás; si le quitas el 아무리 pierde la fuerza. Muy útil para quejarte: 아무리 찾아도 없어요.

## Forma
`아무리 + A/V-아도/어도 (바쁘다→아무리 바빠도, 찾다→아무리 찾아도)`

|  | 받침 X | 받침 O |
|---|---|---|
| 형용사 | 예쁘다 → 아무리 예뻐도 | 작다 → 아무리 작아도 |
| 동사 | 말하다 → 아무리 말해도 | 먹다 → 아무리 먹어도 |

## Appendix del libro (문법 해설)
**Significado (p. 259):** 앞선 행위나 상태를 강조할 때 쓰는 표현으로 정도가 매우 심함을 나타낼 때 쓴다. (por más que…)

**Combinación:** 형용사, 동사

Ejemplos del appendix:

- `저는 아무리 바빠도 아침은 꼭 먹고 다녀요.`
- `혹시 차 열쇠 못 봤어요? 책상 위에 둔 것 같은데 아무리 찾아도 없네요.`
- `남자 친구에게 약속 시간을 잘 지키라고 아무리 말해도 듣지 않아요.`

## Errores típicos de hispanohablantes
- Dejar el `-아도/어도` sin `아무리`: se pierde el énfasis.
- Confundir `아무리` con `아무` (unidad 6): `아무리` va con verbo, `아무 N도` con sustantivo.
- Poner `아무리` al final: siempre va delante.

## Machete para Pedro
`아무리 + A/V-아도/어도 (바쁘다→아무리 바빠도, 찾다→아무리 찾아도)`

- 아무리 일이 많아도 좀 쉬면서 하세요. → *Por más trabajo que tenga, hágalo descansando un poco.*
- 저는 아무리 피곤해도 운동을 꼭 하고 자요. → *Por más cansado que esté, hago ejercicio antes de acostarme.*
- 아무리 찾아도 안 보여요. → *Por más que busco, no aparece.*
- 아무리 할 일이 많아도 지금은 푹 쉬어야 돼요. → *Por más que tenga cosas que hacer, ahora le toca descansar bien.*
