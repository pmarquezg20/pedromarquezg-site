# Reading - 추석 (읽기)

Unidad: [[Korean 2A/2B/Unidad 16/Index - Unidad 16|Unidad 16: 설날에는 밥 대신 떡국을 먹어요]]
Fuente: Student Book 2B · 읽기 de la unidad 16

## Texto original

> 추석은 음력 8월 15일로 한국의 중요한 명절입니다. 추석은 한 해 농사가 잘 끝난 것을 조상들께 감사하는 날입니다. 추석 아침에는 새로 추수한 곡식과 과일로 차례를 지낸 후 성묘를 하러 갑니다. 그리고 송편을 만들어서 이웃들과 나눠 먹고 오랜만에 만난 친척들과 이야기를 하면서 즐거운 시간을 보냅니다.
>
> 추석에 하는 전통 놀이에는 씨름, 강강술래 등이 있습니다. 추석날 밤에는 일 년 중에서 가장 크고 밝은 보름달을 볼 수 있는데 사람들은 그 달을 보면서 소원을 빕니다.

## Traducción

> Chuseok es una festividad importante de Corea, el 15 del octavo mes del calendario lunar. Chuseok es el día en que se agradece a los antepasados que las labores del campo del año hayan terminado bien. La mañana de Chuseok, después de celebrar el rito *charye* con los granos y frutas recién cosechados, se va a visitar las tumbas familiares. Y se hace *songpyeon* para compartirlo con los vecinos, y se pasa un rato agradable conversando con los parientes a quienes no se veía hace mucho.
>
> Entre los juegos tradicionales que se hacen en Chuseok están el *ssireum*, el *ganggangsullae*, etc. La noche de Chuseok se puede ver la luna llena más grande y brillante de todo el año, y la gente pide deseos mientras la mira.

---

## Por qué este texto se siente difícil

No es el vocabulario — es que casi cada sustantivo lleva **una frase entera pegada adelante** modificándolo. En español eso va *después* ("el día **en que se agradece**"); en coreano va *antes*.

> 한 해 농사가 잘 끝난 것을 조상들께 감사하**는** **날**
> ← todo eso modifica a 날 (día)

> [!tip] Truco de lectura
> Busca primero el **último sustantivo** del bloque y lee hacia atrás.
> `...감사하는 **날**입니다` → "es un **día**" → ¿qué día? → el de agradecer.

## Desglose frase por frase

### 1. 추석은 음력 8월 15일로 한국의 중요한 명절입니다.
*Chuseok es una festividad importante de Corea, el 15 del octavo mes lunar.*

| Coreano | Español |
|---|---|
| 추석 | Chuseok (fiesta de la cosecha) |
| 음력 | calendario lunar (陰曆) ↔ 양력 = solar |
| **-로** | aquí = "siendo / en la fecha de" |
| **-의** | de (posesivo) · 한국**의** = de Corea |
| 중요하다 | ser importante → 중요**한** = importante |
| 명절 | festividad tradicional |

### 2. 추석은 한 해 농사가 잘 끝난 것을 조상들께 감사하는 날입니다.
*Chuseok es el día en que se agradece a los antepasados que la cosecha del año terminó bien.*

Dos modificadores encajados, uno dentro del otro:
- 농사가 잘 끝**난 것** = **el hecho de que** la cosecha terminó bien (`-(으)ㄴ` pasado + `것` nominaliza)
- [eso]를 조상들께 감사하**는 날** = **el día en que** se agradece [eso] a los antepasados (`-는` presente)

| Coreano | Español |
|---|---|
| 한 해 | un año (해 = año, palabra nativa) |
| 농사 | labores del campo, agricultura |
| 잘 | bien |
| 끝나다 | terminar(se), acabar → 끝**난** = que terminó |
| 것 | cosa, hecho — convierte una frase en sustantivo |
| 조상 | antepasado · 조상**들** = plural |
| **-께** | versión honorífica de 에게 ("a") — se usa con los antepasados |
| 감사하다 | agradecer, dar gracias |
| 날 | día |

### 3. 추석 아침에는 새로 추수한 곡식과 과일로 차례를 지낸 후 성묘를 하러 갑니다.
*La mañana de Chuseok, después de celebrar el charye con granos y frutas recién cosechados, se va a visitar las tumbas.*

| Coreano | Español |
|---|---|
| 아침 | mañana |
| 새로 | recién, nuevamente |
| 추수하다 | cosechar → 추수**한** = cosechado |
| 곡식 | grano, cereal |
| 과일 | fruta |
| **-로** | con (instrumento) |
| 차례 | rito ancestral de las festividades |
| 지내다 | celebrar (un rito); pasar (tiempo) |
| **-(으)ㄴ 후** | **después de** ← de [[Korean 2A/2B/Unidad 14/Index - Unidad 14\|U14]] |
| 성묘 | visita a las tumbas familiares |
| **-(으)러 가다** | ir **a** hacer algo |

### 4. 그리고 송편을 만들어서 이웃들과 나눠 먹고 오랜만에 만난 친척들과 이야기를 하면서 즐거운 시간을 보냅니다.
*Y se hace songpyeon para compartirlo con los vecinos, y se pasa un rato agradable conversando con los parientes a quienes no se veía hace mucho.*

| Coreano | Español |
|---|---|
| 송편 | songpyeon, pastel de arroz en media luna |
| 만들다 | hacer, fabricar |
| 이웃 | vecino |
| **-과/와** | con, y · 이웃들**과** = con los vecinos |
| 나누다 | repartir → 나눠 먹다 = **compartir** comida |
| 오랜만에 | después de mucho tiempo |
| 만나다 | encontrarse → 만**난** 친척들 = los parientes que encontró |
| 친척 | pariente |
| **-(으)면서** | **mientras** (dos acciones a la vez) |
| 즐겁다 | ser agradable → 즐거**운** *(irregular ㅂ)* |
| 시간을 보내다 | pasar el tiempo |

### 5. 추석에 하는 전통 놀이에는 씨름, 강강술래 등이 있습니다.
*Entre los juegos tradicionales que se hacen en Chuseok están el ssireum, el ganggangsullae, etc.*

| Coreano | Español |
|---|---|
| 전통 | tradición / tradicional |
| 놀이 | juego |
| 씨름 | lucha tradicional coreana |
| 강강술래 | danza circular tradicional |
| 등 | etcétera |

### 6. 추석날 밤에는 일 년 중에서 가장 크고 밝은 보름달을 볼 수 있는데 사람들은 그 달을 보면서 소원을 빕니다.
*La noche de Chuseok se puede ver la luna llena más grande y brillante del año, y la gente pide deseos mientras la mira.*

| Coreano | Español |
|---|---|
| 밤 | noche |
| 일 년 중에서 | de entre todo el año |
| 가장 | el más (superlativo) |
| 크다 | ser grande → 크**고** = grande y... |
| 밝다 | ser brillante, ser claro → 밝**은** = brillante |
| 보름달 | **luna llena** (보름 = día 15 lunar + 달 = luna) |
| 달 | luna |
| **-는데** | conecta: "y resulta que..." |
| 그 | ese/esa · 그 달 = esa luna |
| 소원 | deseo |
| 빌다 | pedir, rogar |

> [!warning] 빌다 → 빕니다
> La ㄹ cae ante ㅂ — igual que 말다 → 맙시다. Y **소원을 빌다** es expresión fija: "pedir un deseo".

> [!tip] 크고 밝은 — encadenar adjetivos
> Dos adjetivos describiendo lo mismo: el primero lleva `-고` y solo el último lleva `-(으)ㄴ`.
> Patrón: **A-고 + B-(으)ㄴ + sustantivo** → 가장 크**고** 밝**은** 보름달.

## Gramática del texto

| Regla | Dónde aparece |
|---|---|
| `-(으)ㄴ` modificador pasado | 끝**난** 것, 추수**한** 곡식, 만**난** 친척 |
| `-는` modificador presente | 감사하**는** 날, 하**는** 놀이 |
| `-(으)ㄴ 후` | 차례를 지**낸 후** ← [[Korean 2A/2B/Unidad 14/Index - Unidad 14\|U14]] |
| `-(으)러 가다` | 성묘를 하**러** 갑니다 |
| `-(으)면서` | 이야기를 하**면서**, 보**면서** |
| `-는데` | 볼 수 있**는데** |
| Irregular ㅂ | 즐겁다 → 즐거**운** |
| Irregular ㄹ | 빌다 → **빕니다** |

## Contexto cultural
- **추석** es la fiesta de la cosecha, el equivalente coreano de Acción de Gracias. Cae el 15 del octavo mes lunar (septiembre u octubre en el calendario solar).
- **차례** = rito de ofrenda a los antepasados que se hace en casa la mañana de la fiesta.
- **성묘** = después del 차례 se va al cementerio familiar a limpiar y visitar las tumbas.
- **송편** = pastel de arroz relleno (sésamo, castaña, frijol) cocido al vapor sobre agujas de pino (송 = pino).
- **씨름** = lucha tradicional coreana, en arena, agarrando el 샅바 (faja).
- **강강술래** = danza circular que hacen las mujeres bajo la luna llena, cantando.
- Se contrasta con **설날** (Año Nuevo lunar), el otro gran 명절 y tema del título de esta unidad.
